# Avik Ghosh — Python Backend Developer Portfolio

A responsive, dark-themed static portfolio built with HTML, CSS and vanilla JavaScript. It is ready for GitHub Pages.

## Before publishing
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your real email address.
2. Check the experience dates and skills for accuracy.
3. Add real GitHub repository/demo links to the project cards if you want them clickable.
4. Add a PDF resume to this folder (for example `resume.pdf`) and add a Resume link in the navigation if desired.

## Publish with GitHub Pages
1. Sign in to https://github.com/
2. Click **New repository**.
3. Name it exactly `YOUR-GITHUB-USERNAME.github.io` (replace with your GitHub username).
4. Set visibility to **Public**, then create the repository.
5. On the repository page, choose **Add file → Upload files**.
6. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder. You can also upload your resume PDF.
7. Commit the files to the `main` branch.
8. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**.
9. Select branch **main** and folder **/(root)**, then click **Save**.
10. Wait a few minutes. Your site will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/`

## Update the site
Edit the files, upload the updated versions to the same repository, and commit the changes. GitHub Pages will publish the update automatically.
